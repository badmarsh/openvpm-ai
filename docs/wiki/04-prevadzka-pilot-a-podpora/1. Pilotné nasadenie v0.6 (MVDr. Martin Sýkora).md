## 3. Transparentne uvádzané obmedzenia (Known Gaps — v0.6)

Podľa princípu maximálnej transparentnosti voči pilotným klientom a regulátorom:

| Oblasť | Skutočný stav | Plánovaná oprava |
|--------|---------------|------------------|
| Priame B2G podanie KVEPIS | Len XML export; automatické podanie REST chýba | v0.7 (Q4 2026)   |
| Certifikácia integrácie e-Kasa s FS SR | Prebieha; driver je technicky kompatibilný | Q4 2026          |
| PetExpert live API s produkčnými credentials | Len payload builder; live API chýba | v0.7 (Q1 2027)   |
| Lokálna tlač cez FiskalPRO z cloudu | Vyžaduje lokálny Tray Agent alebo VPN | v0.7 (Windows/macOS agent) |
| Offline klinický EMR (bez internetu) | e-Kasa offline funguje; klinický EMR potrebuje spojenie | v1.0 (ServiceWorker) |
| Reálne produkčné B2G podania KVEPIS | 0 reálnych podaní (len testovací endpoint) | Q1 2027          |

## 4. Technologický základ systému

| Vrstva | Technológia |
|--------|-------------|
| Frontend | Next.js 15 (App Router), TypeScript, React 19 |
| UI knižnice | shadcn/ui + Radix UI + Tailwind CSS |
| API    | tRPC + REST API `/api/v1` |
| Databáza | PostgreSQL 16 + Drizzle ORM + Row-Level Security |
| Autentifikácia | NextAuth.js, RBAC, voliteľné TOTP MFA |
| AI modely | Claude 3.5 Sonnet (Anthropic) + Gemini 1.5 Pro (Google Vertex EU) |
| SMS/Email | Telnyx SMS + Resend Email |
| Platobná brána | Stripe + Stripe Connect |
| Úložisko súborov | S3-kompatibilné úložisko alebo MinIO (self-host) |
| Kontajnerizácia | Docker Compose (self-host) alebo Vercel (cloud) |
| Testovanie | Vitest (4 858 testov, 100 % pass rate) + Playwright E2E |

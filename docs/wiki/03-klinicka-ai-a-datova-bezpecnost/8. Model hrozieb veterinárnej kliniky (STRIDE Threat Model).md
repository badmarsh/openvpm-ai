# ⚠️ 8. Model hrozieb veterinárnej kliniky (STRIDE Threat Model)

Tento dokument analyzuje model hrozieb podľa metodiky **STRIDE** pre klinickú prevádzku, dáta pacientov a infraštruktúru OpenVPM AI (`docs/production-readiness/THREAT_MODEL.md`).


---

## 1. Analýza bezpečnostných hrozieb (STRIDE)

| ID  | Vektor ohrozenia (Abuse Case) | Dopad na kliniku | Implementované bezpečnostné protiopatrenie | Zostávajúce riziko (Residual Gap) |
|-----|-------------------------------|------------------|--------------------------------------------|-----------------------------------|
| **T01** | Neautentifikovaný prístup k dashboardu | Únik citlivých pacientskych dát (PHI) | Middleware JWT tokeny; procedúry `protectedProcedure` | Verejné routy musia striktne overovať kontext |
| **T02** | Medziklinický IDOR (prístup k inej klinike) | Únik záznamov konkurenčnej ambulancie | PostgreSQL Row-Level Security (RLS) + `withTenant` GUC | Produkcia musí bežať pod rolou `openpims_app` |
| **T03** | Vertikálna eskalácia práv (viewer mení dáta) | Porušenie integrity zdravotného záznamu | Zákaz mutácií pre rolu viewer na úrovni tRPC routerov | UI skrytie tlačidiel nie je bezpečnosť |
| **T04** | Znovupoužitie relácie po vyhadzove personálu | Neoprávnený vstup prepusteného zamestnanca | `activeSessionOrNull` overuje stav účtu v DB každých 30s | Maximálne oneskorenie 30s         |
| **T05** | Odcudzenie capability tokenu portálu | Prístup k fotkám a dokladom majiteľa | Opaque tokeny, obmedzená platnosť, kontrola domény | Overenie entropie pri generovaní  |
| **T06** | Falšovanie webhookov (Stripe / Telnyx) | Falošné potvrdenie platby | Kryptografické overenie podpisu webhooku cez secret | Nutné strážiť replay window       |
| **T07** | Volanie cron endpointov bez kľúča | Spustenie nočných úloh útočníkom | Povinný Bearer token `CRON_SECRET`         | Slabé heslo je chybou operátora   |
| **T08** | Únik medicínskych snímok a audia (S3) | Porušenie GDPR a lekárskeho tajomstva | Izolované kľúče úložísk viazané na tenant; zákaz public ACL | Úložisko musí mať zapnutý privátny režim |
| **T09** | Prompt Injection útok na AI asistenta | Pokus o únik dát alebo spustenie zápisu | Nástroje viazané na tenant; zápisy vyžadujú `allowWrites` | Model musí overovať človek        |
| **T10** | Prezentácia AI výstupu ako hotovej diagnózy | Poškodenie zdravia zvieraťa | Striktný status *Draft*; modál klinickej kontroly | Povinné zaškolenie lekárov        |
| **T11** | Odoslanie SMS majiteľovi uhynutého zvieraťa | Traumatizácia klienta, strata reputácie | Povinná a nevypnuteľná brána **Sympathy Gate** | Fail-closed logika v kóde         |
| **T12** | Únik produkčných API kľúčov do Gitu | Kompromitácia cloudových služieb | Skript `verify:oss-release` v CI potvrdzujúci čistotu kódu | Zákaz commitovania tajomstiev     |
| **T13** | Falšovanie pokladničných dokladov e-Kasa | Daňový podvod a pokuta od FS SR | Poradové číslovanie, advisory locks a PKP počítané z kľúča FS | Nutný certifikát FS SR            |
| **T14** | SSRF útok cez e-Kasa API URL  | Prienik do internej siete kliniky | Whitelist povolených HTTPS domén Finančnej správy SR | Zákaz interných IP adries         |

## 2. Hranice dôvery (Trust Boundaries)


1. Prehliadač ↔ Next.js aplikačný server (Session cookie / Portal token).
2. Aplikácia ↔ PostgreSQL databáza (rola s minimálnymi právami `openpims_app`).
3. Aplikácia ↔ Objektové úložisko S3/MinIO (podpísané presigned URL).
4. Aplikácia ↔ Poskytovatelia AI (Zero Data Retention API zmluvy).
5. Aplikácia ↔ Fiškálne rozhranie Finančnej správy SR.

# apps/web (@openpims/web)

Main Next.js 15 application for OpenVPM AI (port **3001** in development).
Features full veterinary clinic management, clinical AI assist (SOAP dictation, multimodal imaging),
Slovak statutory compliance (e-Kasa, KVEPIS, CRSZ), client portal PWA, and marketing studio.

For local setup and run instructions, see the [Quick Start](../../README.md#quick-start-vývoj-a-lokálne-spustenie) in the root README.

# 🔑 5. Kompletná matica oprávnení (RBAC Matrix)

Tento bezpečnostný dokument definuje autorizačnú architektúru a rolovú maticu prístupových práv (**Role-Based Access Control — RBAC**) v systéme OpenVPM AI. Všetky pravidlá sú vynucované na serverovej vrstve (tRPC procedúry, REST handlery, databázové RLS); vizuálne skrytie prvkov v UI slúži len ako používateľská pomôcka.


---

## 1. Globálna taxonómia používateľských rolí

| Identifikátor roly | Slovenský názov | Rozsah právomocí a zodpovednosť |
|--------------------|-----------------|---------------------------------|
| `admin`            | **Správca praxe** | Úplný prístup ku konfigurácii kliniky, správe používateľov, auditným záznamom a financiám. |
| `veterinarian`     | **Veterinárny lekár (MVDr.)** | Plná klinická autorita: finalizácia SOAP, podpisovanie receptov (Rx), Kniha OPL, zobrazovacie metódy. |
| `technician`       | **Veterinárny asistent / sestra** | Zadávanie váhy, vitálnych funkcií, koncepty záznamov, podávanie ordinovaných liečiv. **Zákaz OPL a podpisovania receptov.** |
| `front_desk`       | **Recepcia**    | Plánovanie kalendára, registrácia pacientov a klientov, vystavovanie dokladov, e-Kasa. Bez prístupu k OPL. |
| `portal_user`      | **Majiteľ zvieraťa (Klient)** | Prístup výhradne k vlastným zvieratám a faktúram cez zabezpečený capability token (`/portal/:token`). |
| `service_cron`     | **Systémový cron / servisný agent** | Automatizovaný proces pre nočný výmaz audia, upomienky a overovanie záloh. |

# ✅ 4. Go-Live Checklist pre spustenie novej kliniky

Tento prevádzkový kontrolný zoznam (**Go-Live Checklist**) slúži ako povinný pre-flight protokol pred prepnutím akejkoľvek novej veterinárnej kliniky do ostrej produkčnej prevádzky (`docs/production-readiness/GO_LIVE_CHECKLIST.md`).


---

## 1. Softvér a integrita kódu (Software Gate)

- [ ] Zaznamenaný a schválený presný produkčný Git commit SHA.
- [ ] Inštalácia závislostí cez `pnpm install --frozen-lockfile`.
- [ ] Spustenie overenia čistoty open-source licencie `pnpm verify:oss-release`.
- [ ] Úspešná statická typová kontrola `pnpm type-check`.
- [ ] Všetky automatizované testy zelené (`pnpm test`, 4 858 testov, 100 % pass rate).
- [ ] Produkčný build bez chýb (`pnpm build`).
- [ ] Bezpečnostný audit závislostí (`pnpm audit --prod --audit-level high`).
- [ ] Overenie PostgreSQL Row-Level Security: `pnpm db:rls` a `pnpm db:rls:test` na staging klone databázy.
- [ ] Produkčné healthchecky zelené: `GET /api/health/live` a `GET /api/health/ready`.


---

## 2. Bezpečnostná konfigurácia prostredia (Configuration Gate)

- [ ] `NEXTAUTH_SECRET` je unikátny kryptografický reťazec s dĺžkou aspoň 32 bajtov.
- [ ] Vynútené výhradne šifrované HTTPS spojenie (HSTS, TLS 1.3).
- [ ] Databázové pripojenie aplikácie beží pod rolou s minimálnymi právami `openpims_app`.
- [ ] Objektové úložisko S3 / MinIO má zapnutý prísne privátny režim (žiadne verejné ACL).
- [ ] Podpísaná zmluva DPA s poskytovateľmi AI (Anthropic / Google Vertex EU) so zárukou Zero Data Retention.
- [ ] Nastavený a otestovaný tajný kľúč `CRON_SECRET` pre zabezpečenie nočných úloh.


---

## 3. Klinická pripravenosť ambulancie (Clinic Gate)

- [ ] Overená konektivita počítačov a tabletov na klinike.
- [ ] Skúšobný import dát z predchádzajúceho systému (CSV Dry-run) a overenie počtu kariet.
- [ ] Jedno kompletné vyšetrenie pacienta odsimulované naživo (príjem, SOAP, váha, recept, e-Kasa doklad).
- [ ] Overenie tlače pokladničných dokladov na termináli FiskalPRO / VRP2.
- [ ] Úspešný prvý manuálny export a záloha databázy.
- [ ] Určený zodpovedný vedúci lekár (Veterinary Champion) a kontakt na technickú podporu.

> ⚠️ **Dôležité:** Ak je čo i len jeden bod kategórie P0 nesplnený, spustenie kliniky do ostrej prevádzky je **zablokované (NO-GO)** až do odstránenia prekážky.

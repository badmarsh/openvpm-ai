# 🗺️ 5. Slovenský integračný katalóg (Veľkoobchody & Diagnostika)

Tento integračný katalóg definuje technickú mapu partnerov a zariadení na slovenskom veterinárnom trhu, ich komunikačné protokoly, podporované dátové formáty a príslušné súbory v kódovej báze OpenVPM AI.


---

## 1. Distribútori liečiv a spotrebného materiálu (Wholesale)

Automatizovaný import dodacích listov zabezpečuje modul `apps/web/lib/inventory/wholesaler-import.ts`:

| Distribútor | Formát súboru | Mapované polia a špecifikácia |
|-------------|---------------|-------------------------------|
| **CYMEDICA SK s.r.o.** | CSV (oddeľovač bodkočiarka) | Kód tovaru, Názov liečiva, **Číslo šarže (Lot)**, **Dátum exspirácie**, Množstvo, MJ, Nákupná cena bez DPH, Sadzba DPH (10 % pre lieky) |
| **PHARMOS a.s.** | EDI / CSV     | ADC kód, ŠÚKL kód, Názov lieku, Šarža, Expirácia, Dodané množstvo, Veľkoobchodná cena |
| **SAMOHÝL SK, s.r.o.** | CSV s EAN kódmi | **EAN čiarový kód (13 číslic)**, Názov veterinárnej diéty / prípravku, Množstvo, Nákupná cena |
| **Henry Schein SK** | CSV / Tab-delimited | Katalógové číslo materiálu, Názov chirurgického spotrebného materiálu, Množstvo, Nákupná cena |
| **BIOPHARM, s.r.o.** | CSV | Štandardizované CSV s kódmi liekov, šaržami, expiráciami a nákupnými cenami |
| **KOMVET s.r.o.** | Tab-delimited (.txt) | Tabulátorom oddelený export bez hlavičky; bezpečný parser odolný voči bodkočiarkam v názvoch liečiv |
| **SG-Vet s.r.o.** | XML | Štruktúrovaný XML formát s podporou slovenských tagov (`<polozka>`, `<kod_tovaru>`, `<nazov_tovaru>`, `<sarza>`, `<expiracia>`, `<cena_bez_dph>`) |
| **SANVET s.r.o.** | CSV | Automatická detekcia formátu podľa názvu súboru a stĺpcov |
| **PHRAMED / Pharmed** | CSV | Automatická detekcia formátu distribútora |
| **Univerzálny dodávateľ** | Štandardné CSV | Názov položky, Množstvo, Nákupná cena, DPH |

### 1.1 Zákonná bezpečnostná brána pre omamné a psychotropné látky (Zákon č. 139/1998 Z. z.)

Všetky dodacie listy spracovávané cez `wholesaler-import.ts` prechádzajú automatickou kontrolou na prítomnosť regulovaných substancií:
* Regexový filter deteguje prípravky ako **Ketamidor, ketamín, narkamon, calypsol, fentanyl, buprenorfín, butorfanol, torbugesic, dolorex, metadón, diazepam, fenobarbital, propofol, morfín**.
* Pri akejkoľvek zhode systém nastaví `isControlledSubstance: true` a **predvolenú akciu na `skip` (Preskočiť)**.
* Položka nie je automaticky pripísaná k bežným skladovým zásobám; lekár je upozornený na nutnosť manuálneho, autentifikovaného zaevidovania do **Knihy OPL** (`/controlled-substances`).

## 3. Externé referenčné laboratóriá

Pre špecializovanú diagnostiku (histopatológia, genetické testy, titrácia protilátok besnoty):

* **Laboklin SK / DE:** Prepojenie cez HL7 v2.5 a PDF konektor s automatickým párovaním podľa čísla žiadanky alebo čipu zvieraťa.
* **Synlab SK:** Import výsledkov laboratórnych panelov cez HL7/XML.
* **Štátny veterinárny a potravinový ústav (ŠVÚ Zvolen / Bratislava):** Oficiálne nálezy úradných nákaz (besnota TIRC, trichinelóza, africký mor ošípaných AMO) potrebné pre hlásenia KVEPIS.

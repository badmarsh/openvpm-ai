## Method

- History was deepened (`git fetch --unshallow`) so that 923 commits were available. The first-commit date comes from `git log --diff-filter=A --follow`. Agno dispatch files are dated by the epoch in their filename.
- A sprint counts as **DONE** only if its target page changed in a merged PR **and** the named source-contract test exists (`apps/web/lib/__tests__/*-pagekit.test.ts`). The existence of the `.md` file is never evidence.
- Golden Tickets were checked against the exact file:line each ticket cites.
- Agno regression suite re-run after the move: `pytest .agents/agno/tests/test_prompt_templates.py tests/test_pipeline_tools.py` → 43 passed (3 new tests cover the `tasks/sprints/` lookup).
